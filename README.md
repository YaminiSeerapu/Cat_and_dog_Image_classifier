# Cat_and_dog_Image_classifier
This project is a deep learning-based image classifier designed to distinguish between images of cats and dogs. Using a Convolutional Neural Network (CNN), the model achieves high accuracy by leveraging advanced techniques like data augmentation, dropout, and batch normalization.

# Features
- Binary Classification: Classifies images as either "Cat" or "Dog."
- Data Preprocessing: Includes normalization and augmentation for better generalization.
- Model Architecture: Built using CNN layers for feature extraction and classification.
- Real-World Testing: Successfully tested with real-world images.

# Technologies Used
- Programming Language: Python
- Deep Learning Framework: TensorFlow/Keras
- Libraries: NumPy, Matplotlib, OpenCV (optional for image preprocessing)
